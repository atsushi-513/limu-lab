Datasets

Moving Object Detection Evaluation Dataset

A video dataset for evaluating moving object detection methods. It provides indoor and outdoor video sequences together with ground-truth annotations of moving object regions.

  • Dataset↗

Related Publication

Evaluation Report of Integrated Background Modeling Based on Spatio-temporal Features

Yosuke Nonaka, Atsushi Shimada, Hajime Nagahara, Rin-ichiro Taniguchi

IEEE Workshop on Change Detection in conjunction with CVPR 2012, 2012

KOMATSUNA Dataset

A dataset for 3D plant phenotyping of komatsuna. It includes multi-view images, RGB-D data, and ground-truth annotations of leaf regions.

Related Publication

An easy-to-setup 3D phenotyping platform for KOMATSUNA dataset

Computer Vision Problems in Plant Phenotyping (CVPPP), pp. 1–8, 2017

Person Re-identification Visualization Tool

A visualization tool for person re-identification across multiple cameras. It supports visual inspection and analysis of correspondence results between people observed by different cameras.

Related Publication

IMU-based Indoor Positioning

An indoor positioning system using a chest-mounted inertial measurement unit. It combines pedestrian dead reckoning with map matching to estimate a user's indoor position.

Related Publication

OpenLA

An open-source Learning Analytics library for analyzing learning log data. It supports data transformation, extraction, aggregation, and visualization of interaction logs such as those generated by digital learning materials.
